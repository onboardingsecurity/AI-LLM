# AI A에게 줄 작업 묶음

이 파일 내용을 첫 메시지에 그대로 붙여 넣고, `js/app.js` 파일(또는 전체 내용)을 함께 준다. 이 파일은 `records/plan.md`의 요청·검사와 같은 내용이다(기준은 plan.md).

---

## 요청

밈 카드 스튜디오(순수 HTML/JS 웹앱)의 `js/app.js`를 고쳐 달라. 템플릿을 저장할 때 같은 이름이 이미 있으면 이름 뒤에 ` (2)`, ` (3)`처럼 가장 작은 빈 번호를 붙이는 기능이다. 기준은 아래 검사 K01~K10이다. 검사는 바꾸지 말고 코드만 고친다. 고치는 파일은 `js/app.js`뿐이다.

이 대화는 요청 5회, 15분 안에 끝나야 한다. 첫 답변에서 최대한 많이 끝내고, 마지막에는 아래 "인수인계 문서"를 꼭 남겨라.

### 범위
- 먼저 할 일: 새 템플릿 저장(`saveNewTemplate`)에 중복 이름 정리를 적용한다(K01~K08).
- 남는 일은 다음 작업자가 잇는다: 수정 저장(`updateSelectedTemplate`, K09)과 JSON 가져오기(`importFile`, K10). 시간이 되면 해도 되지만, 못 하면 못 한 것으로 인수인계 문서에 적어라.

### 코드에 대해 알려 주는 것
- 템플릿 이름은 `cleanName()`이 공백을 정리하고 40자로 자른다. 입력칸은 15자까지만 입력된다. 이름을 비우면 `autoName()`이 "템플릿 N"을 붙인다(이 동작은 유지).
- 저장소의 모든 템플릿(기본 템플릿 3개 포함: "기본 템플릿 1~3")은 `dbGetAll()`로 읽는다. 이름이 겹치는지는 기본 템플릿 이름까지 포함해 본다.
- 직접 만든 템플릿은 최대 3개다(`USER_TEMPLATE_MAX`, 기본 템플릿은 세지 않음). 이 한도 동작은 바꾸지 않는다.
- 번호는 가장 작은 빈 번호를 쓴다. 예: "고양이", "고양이 (3)"이 있으면 새 이름은 "고양이 (2)".

### 검사 10개 (고정, 바꾸지 말 것)
시작 조건: 직접 만든 템플릿 0개(기본 템플릿 3개는 있음). 코드를 실행할 수 없으면 검사를 머릿속으로 따라가 보고, 확신이 없는 검사는 확신이 없다고 적어라.

| ID | 입력 | 기대값 |
|----|------|--------|
| K01 | 이름 "고양이"로 새 템플릿 저장 | 목록에 "고양이" |
| K02 | 이름 "고양이"로 한 번 더 저장 | 목록에 "고양이", "고양이 (2)" |
| K03 | 이름 "고양이"로 세 번째 저장 | 목록에 "고양이 (3)" 추가(직접 만든 템플릿 3개 한도 경계) |
| K04 | K03 상태에서 "고양이 (2)"를 삭제하고 "고양이"로 저장 | 가장 작은 빈 번호인 "고양이 (2)" |
| K05 | 이름을 비우고 저장 | "템플릿 1" (기존 동작 유지) |
| K06 | 15자 이름 `가나다라마바사아자차카타파하가`를 두 번 저장 | 두 번째 이름은 같은 15자 뒤에 " (2)"가 붙은 19자 그대로이고 잘리지 않음 |
| K07 | "고양이"가 있는 상태에서 "고양이 "(끝에 공백)로 저장 | "고양이 (2)" |
| K08 | 이름 "기본 템플릿 1"로 저장 | "기본 템플릿 1 (2)" |
| K09 | "A"와 "B"가 있는 상태에서 "A"를 불러와 이름을 "B"로 바꿔 수정 저장. 이어서 이름을 자기 이름 그대로 두고 수정 저장 | 앞의 결과는 "B (2)", 뒤의 결과는 이름 변경 없음 |
| K10 | 이름이 "고양이"인 템플릿 1개의 JSON을 "고양이"가 있는 상태에서 가져오기. 이어서 3개 한도를 넘기는 상태에서 가져오기 | 앞의 결과는 "고양이 (2)"로 추가, 뒤의 결과는 기존처럼 아무것도 가져오지 않고 한도 알림 |

### 답변 형식
- 파일 전체를 다시 쓰지 말고, 바뀐 함수만 파일 이름·함수 이름과 함께 전체 코드로 보여 줘라(붙여 넣어 바꿀 수 있게).
- 검사 K01~K10 각각 통과 예상(PASS), 실패 예상(FAIL), 모름 중 하나를 적어라.

## 인수인계 문서 (작업을 멈출 때 꼭 이 형식으로 작성)

아래 일곱 제목을 그대로 쓰고 채워라. 다음 작업자는 이 대화를 볼 수 없고 저장소와 이 문서만 받는다.

```
버전 ID: (비워 둔다. 사용자가 채운다)

## 목표
## 현재 상태
## 실행 명령
## 통과 검사
## 남은 문제
## 다음 행동
## 건드리지 말 것
```

- 목표: 만들려는 기능 한 문장
- 현재 상태: 어디까지 했나, 어떤 함수를 어떻게 바꿨나
- 실행 명령: 저장소 루트에서 `python3 -m http.server 8765` 후 http://localhost:8765/ 접속
- 통과 검사: K01~K10 각각 PASS/FAIL/모름
- 남은 문제: 안 되는 것, 확신이 없는 것(첫 실패 검사부터)
- 다음 행동: 다음 작업자가 가장 먼저 할 일
- 건드리지 말 것: 바꾸면 안 되는 것(검사 10개, 3개 한도, 기본 템플릿 삭제 불가 등)
