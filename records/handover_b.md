# AI B가 남긴 인수인계 문서

AI B(Claude 무료)가 작업을 마치며 남긴 문서를 그대로 옮겼다. 버전 ID 줄은 B가 쓰지 않았다. B 종료 버전 ID: 54e76d52e87983e4ff4438109d88e7211487cbb5

## 목표

템플릿 이름이 중복되면 가장 작은 빈 번호(이름 (2), 이름 (3))를 붙여 고유한 이름으로 저장한다. 적용 대상은 새 저장, 수정 저장, JSON 가져오기다.

## 현재 상태

js/app.js만 수정했다.

- uniqueTemplateName(name, records, ownId): 수정 저장 때 자기 자신을 제외할 수 있고, 40자를 넘을 때만 앞부분을 자른다.
- saveNewTemplate(): 이전 작업자가 수정한 그대로다.
- updateSelectedTemplate(): 다른 템플릿과 겹치면 번호를 붙이고, 자기 이름 그대로면 바뀌지 않는다. 저장 뒤 이름 입력칸을 새 이름으로 맞춘다.
- importFile(): 한도 검사를 통과한 뒤 가져온 이름을 기존 이름과 파일 안 이름 모두에 대해 중복 처리한다. 3개 한도를 넘으면 아무것도 가져오지 않는다.
- 브라우저 실행과 구문 검사는 하지 않았다. 코드를 읽고 추정만 했다.

## 실행 명령

저장소 루트에서 python3 -m http.server 8765 를 실행하고, 브라우저에서 http://localhost:8765/ 에 접속한다.

## 통과 검사

- K01~K10: 모두 PASS 예상 (실행하지 않음)

## 남은 문제

1. K01~K10 브라우저 실검을 아직 하지 않았다.
2. K06은 이름 입력칸의 maxlength가 15인지 HTML에서 확인하지 못했다.
3. importFile의 이름 중복 처리와 저장(dbAddMany)은 별도 트랜잭션이라, 다른 탭에서 동시에 저장하면 이름이 겹칠 수 있다.
