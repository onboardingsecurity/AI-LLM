## 고정 검사 10개

시작 조건: 직접 만든 템플릿 0개(기본 템플릿 3개는 있음). 실행은 브라우저(`python3 -m http.server 8765`, http://localhost:8765/)에서 사용자가 직접 한다.

| ID | 입력 | 기대값 |
|----|------|--------|
| K01 | 이름 "고양이"로 새 템플릿 저장 | 목록에 "고양이" |
| K02 | 이름 "고양이"로 한 번 더 저장 | 목록에 "고양이", "고양이 (2)" |
| K03 | 이름 "고양이"로 세 번째 저장 | 목록에 "고양이 (3)" 추가(직접 만든 템플릿 3개 한도 경계) |
| K04 | K03 상태에서 "고양이 (2)"를 삭제하고 "고양이"로 저장 | 가장 작은 빈 번호인 "고양이 (2)" |
| K05 | 이름을 비우고 저장 | "템플릿 1" (기존 동작 유지) |
| K06 | 15자 이름 `가나다라마바사아자차카타파하가`를 두 번 저장 | 두 번째 이름은 같은 15자 뒤에 " (2)"가 붙은 19자 그대로이고 잘리지 않음 |
| K07 | "고양이"가 있는 상태에서 "고양이 "(끝에 공백)로 저장 | "고양이 (2)" |
| K08 | 이름 "기본 템플릿 1"로 저장 | "기본 템플릿 1 (2)" |
| K09 | "A"와 "B"가 있는 상태에서 "A"를 불러와 이름을 "B"로 바꿔 수정 저장. 이어서 이름을 자기 이름 그대로 두고 수정 저장 | 앞의 결과는 "B (2)", 뒤의 결과는 이름 변경 없음 |
| K10 | 이름이 "고양이"인 템플릿 1개의 JSON을 "고양이"가 있는 상태에서 가져오기. 이어서 3개 한도를 넘기는 상태에서 가져오기 | 앞의 결과는 "고양이 (2)"로 추가, 뒤의 결과는 기존처럼 아무것도 가져오지 않고 한도 알림 |
