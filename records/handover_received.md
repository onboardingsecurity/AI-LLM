## 목표

새 템플릿을 저장할 때 기존 이름과 중복되면 가장 작은 빈 번호를 붙여 고유한 이름으로 저장한다.

## 현재 상태

js/app.js에 uniqueTemplateName(name, records) 함수를 추가하고 saveNewTemplate()을 수정했다.

- 저장된 모든 템플릿 이름을 비교한다. 기본 템플릿도 포함한다.
- 중복 시 이름 (2), 이름 (3) 순으로 가장 작은 빈 번호를 선택한다.
- 빈 이름의 자동 생성 동작과 사용자 템플릿 3개 제한을 유지한다.
- 수정된 파일의 JavaScript 구문 검사를 실행했다. 브라우저에서 K01~K10을 실제 실행하지는 않았다.

## 실행 명령

저장소 루트에서 다음 명령을 실행한다.

python3 -m http.server 8765

브라우저에서 http://localhost:8765/에 접속한다.

## 남은 문제

1. updateSelectedTemplate()에서 수정 저장 시 이름 중복을 처리하지 않는다.
2. importFile()에서 JSON 가져오기 시 이름 중복을 처리하지 않는다.
3. K01~K10 브라우저 실검은 아직 수행하지 않았다.

## 다음 행동

1. K01~K08을 브라우저에서 확인한다.
2. updateSelectedTemplate()을 수정해 다른 템플릿과 이름이 겹칠 때 가장 작은 빈 번호를 붙이되, 자기 이름 그대로 저장할 때는 이름을 바꾸지 않는다.
3. importFile()에서 가져온 템플릿 이름도 중복 처리한다. 사용자 템플릿 3개 제한을 초과하면 기존 동작대로 아무것도 가져오지 않는다.
4. K09와 K10을 포함해 전체 검사를 실행한다.
