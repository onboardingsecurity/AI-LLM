# 보안 점검 리스트 — 논문과 데이터를 외부로 옮기기 전에

**목적**: 논문·원자료·스크립트·AI 대화 기록을 GitHub나 제출 ZIP, 외부 AI 서비스로 옮기기 전에, 올라가면 안 되는 것이 들어 있지 않은지 점검합니다.
**범위**: 시스템 변경, 외부 연결, 키 값 노출과 관리, 개인정보, 데이터 출처와 내려받은 파일.
**점검 방법**: "보안 점검해줘"라고 하면 항목마다 명령을 실제로 실행해 확인하고(점검 스크립트를 만든 뒤에는 `node scripts/check.mjs sec`도 실행), 사용자만 확인할 수 있는 항목은 ➖로 두고 무엇을 확인해야 하는지 적습니다. 이전 결과를 그대로 옮기지 않습니다. 결과는 요약 한 줄과 항목별 표로 보고하고, 실패가 있으면 이유와 대안을 함께 적습니다. 이 문서의 상태·근거 열은 사용자 승인 후 갱신합니다.

> 참고한 형식: 브랜치 `ai-agent-talking-about-me`의 `docs/SECURITY-CHECKLIST.md`. 기록 원문·이름 목록 항목은 이 프로젝트에 맞게 줄이고, 내려받은 공개 데이터·문헌 출처·ZIP 내용 항목을 더했습니다.
> 모든 명령은 프로젝트 폴더에서 실행하며 읽기만 합니다.
