# 보안 점검 리스트 — 코드와 문서를 외부로 옮기기 전에

**목적**: 코드·문서·기록을 GitHub나 외부 AI 서비스로 옮기기 전에, 올라가면 안 되는 것이 들어 있지 않은지 점검합니다.
**범위**: 시스템 변경, 외부 연결, 키 값 노출과 관리, 개인정보, 기록 파일.
**점검 방법**: "보안 점검해줘"라고 하면 `node scripts/check.mjs sec`을 실제로 실행하고, 스크립트가 못 보는 항목은 사용자에게 확인합니다. 이전 결과를 그대로 옮기지 않고, 사용자만 확인할 수 있는 항목은 ➖로 두고 무엇을 확인해야 하는지 적습니다. 결과는 요약 한 줄과 항목별 표로 보고하고, 실패가 있으면 어디서 무엇이 실패했는지와 통과하기 위한 대안을 함께 적습니다. 이 문서의 상태·근거 열은 사용자 승인 후 갱신합니다. 사용자 확인 항목(S13~S16)은 이 문서의 상태 열이 ✅로 바뀐 뒤에야 스크립트가 통과로 읽습니다.

> 참고한 형식: 브랜치 `ai-passkey-on-my-introduction-page`의 `docs/SECURITY-CHECKLIST.md`. 서버·패스키·Supabase·Vercel 항목은 이 프로젝트에 없어 뺐고, 기록 원문과 외부 AI 서비스 항목을 더했습니다.
> 모든 명령은 프로젝트 폴더에서 실행하며 읽기만 합니다.

## 상태 범례

| 표시 | 뜻 |
|---|---|
| ✅ 통과 | 확인했고 문제 없음 |
| ⏳ 진행중 | 알려진 위험이 있고 대응이 남음 |
| ➖ 미확인 / 사용자 확인 | 사용자만 확인·결정할 수 있거나 아직 확인하지 못함 |
| ❌ 실패 | 올라가면 안 되는 것이 발견됨 |

## 점검 항목

### A. 키 값 노출과 관리

| ID | 점검 항목 | 확인 방법 | 상태 | 근거 (2026-10-25) |
|---|---|---|---|---|
| S01 | 비밀키·토큰·API 키 값이 파일에 없다 | 스크립트 | ✅ | 올라갈 파일에서 키·토큰·개인키 패턴 없음. 이 프로젝트는 AI 서비스 키를 쓰지 않음(웹 화면에서 대화) |
| S02 | 기록 원문·키 파일·`node_modules`가 저장소에서 제외된다 | 스크립트(`git check-ignore`) | ✅ | `records/*`(README만 예외), `.env`, `.env.local`, `node_modules/`가 ignore 됨 |

| ID | 점검 항목 | 확인 방법 | 상태 | 근거 |

| S04 | 이메일·전화번호·주민번호형·내 컴퓨터 경로가 없다 | 스크립트 | ✅ | 올라갈 파일에서 패턴 없음. 본인 이름은 서사 문서에 있어야 하므로 이 항목의 대상이 아님 |
