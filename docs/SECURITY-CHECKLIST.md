# 보안 점검 리스트 — 원고와 기록을 외부로 옮기기 전에

**목적**: 소설 원고·실제 경험 기록·AI 대화 내용을 GitHub나 제출 플랫폼, 외부 AI 서비스로 옮기기 전에, 올라가면 안 되는 것이 들어 있지 않은지 점검합니다. 이 소설은 사용자의 실제 삶을 소재로 하므로 다른 사람의 실명과 민감한 사연이 들어갈 수 있고, 그대로 공개하지 않는 것이 과제의 조건입니다.
**범위**: 시스템 변경, 외부 연결, 키 값 노출과 관리, 개인정보와 가명 처리, 원고의 공개 범위, 외부 AI 서비스로 보내는 기록.
**점검 방법**: "보안 점검해줘"라고 하면 항목마다 명령을 실제로 실행해 확인하고(점검 스크립트를 만든 뒤에는 `node scripts/check.mjs sec`도 실행), 사용자만 확인할 수 있는 항목은 ➖로 두고 무엇을 확인해야 하는지 적습니다. 이전 결과를 그대로 옮기지 않습니다. 결과는 요약 한 줄과 항목별 표로 보고하고, 실패가 있으면 어디서 무엇이 실패했는지와 통과하기 위한 대안을 함께 적습니다. 상태 개수는 직접 센 값만 말합니다. 이 문서의 상태·근거 열은 사용자 승인 후 갱신합니다.

> 2026-11-02에 다른 세션에서 쓴 보안 점검표(2026-11-01, S01~S12)와 합쳤습니다. 기존 ID는 바꾸지 않았고, 이전 세션에만 있던 시스템 변경 항목은 S17로 추가했습니다.

> 참고한 형식: 브랜치 `ai-agent-talking-about-me`와 `ai-first-paper-written-with-claude`의 `docs/SECURITY-CHECKLIST.md`. 서버·패키지·데이터 출처 항목은 이 프로젝트에 없어 뺐고, 원고 공개 범위와 가명 처리 항목을 강화했습니다.
> 모든 명령은 프로젝트 폴더에서 실행하며 읽기만 합니다.
> 요구사항은 [REQUIREMENTS.md](REQUIREMENTS.md)에서 따로 관리합니다.
