# 보안 점검 리스트 — 사이트·문서·장치를 외부로 옮기기 전에

**목적**: 공개 사이트, 지원 문서, 장치 ZIP을 GitHub나 호스팅, 제출 플랫폼, 외부 AI 서비스로 옮기기 전에 올라가면 안 되는 것이 들어 있지 않은지 점검합니다. 이 사이트는 실제 지원에 쓰므로 누구나 읽을 수 있고, 그 때문에 다른 사람의 실명, 소설 원고, 기록 원문, 키 값이 섞이면 안 됩니다.
**범위**: 시스템 변경, 외부 연결, 개인정보와 실명, 키 값 노출과 관리, 원고와 기록의 공개 범위, 장치 스크립트의 안전, 제출 파일.
**점검 방법**: "보안 점검해줘"라고 하면 항목마다 명령을 실제로 실행해 확인하고, 사용자만 확인할 수 있는 항목은 ➖로 두고 무엇을 확인해야 하는지 적습니다. 이전 결과를 그대로 옮기지 않습니다. 결과는 요약 한 줄과 항목별 표로 보고하고, 실패가 있으면 어디서 무엇이 실패했는지와 통과하기 위한 대안을 함께 적습니다. 상태 개수는 직접 센 값만 말합니다. 이 문서의 상태·근거 열은 사용자 승인 후 갱신합니다.

> 참고한 형식: 브랜치 `ai-character-novel-about-me`(11번)와 `ai-agent-talking-about-me`(9번)의 `docs/SECURITY-CHECKLIST.md`. 이 프로젝트에 맞게 서버·패스키·Supabase 항목은 뺐고, 공개 사이트의 외부 연결, 장치 스크립트, 제출 파일(ZIP·문서) 항목을 더했습니다.
> 모든 명령은 프로젝트 폴더에서 실행하며 읽기만 합니다.
> 요구사항은 [REQUIREMENTS.md](REQUIREMENTS.md)에서 따로 관리합니다.

## 상태 범례
