# 5단계 점검 결과 (JSON 가져오기)

검사 방법: Chrome에서 실제로 JSON을 내보내고 가져온 뒤, IndexedDB 내용을 직접 읽어 가져오기 전후를 대조했다. (이 결과는 자동 점검 스크립트로 만들었으나, 스크립트는 저장소에서 삭제했다. 앱을 고치면 결과가 어긋날 수 있다.)
시험에 쓴 JSON은 [samples/import-tests/](../samples/import-tests/)에 있다(valid.json: 정상, broken-syntax.json: 문법 손상, missing-required.json: 필수 항목 누락).

가져오기 순서는 읽기 → 문법(파싱) → 파일 구조 → 모든 항목 검사 → 저장이다. 앞의 어느 단계에서든 문제가 있으면 저장소에 쓰지 않는다. 항목 검사는 첫 문제에서 멈추지 않고 모든 문제를 모아 알려 준다. 저장은 한 트랜잭션으로 하므로 도중에 실패해도 일부만 남지 않는다. id가 이미 있는 항목만 새 id를 받는다.

## 정상 JSON (C22)

| 상황 | 가져오기 전 | 가져온 뒤 | 결과 |
|---|---|---|---|
| valid.json을 빈 저장소에 가져옴 | 0건 | 3건 | PASS: 원본 3건과 id, 내용, 이미지 해시까지 같음 |
| 같은 파일을 한 번 더 가져옴 | 3건 | 6건 | PASS: 겹친 id 3건만 새 id, 기존 3건 그대로 |

### 화면에 표시된 안내 원문

- 쉼표 하나가 빠진 JSON
  - "broken-syntax.json": JSON 문법이 올바르지 않아 가져오지 않았습니다. 저장된 템플릿은 그대로입니다(가져오기 전 6건, 후 6건).
  - 4번째 줄 3번째 글자 근처 (브라우저 원문: Expected ',' or '}' after property value in JSON at position 61 (line 4 column 3))
- 중간에서 끊긴 JSON
  - "truncated.json": JSON 문법이 올바르지 않아 가져오지 않았습니다. 저장된 템플릿은 그대로입니다(가져오기 전 6건, 후 6건).
  - 60번째 줄 89784번째 글자 근처 (브라우저 원문: Unterminated string in JSON at position 106550 (line 60 column 89784))
- JSON이 아닌 텍스트
  - "plain-text.json": JSON 문법이 올바르지 않아 가져오지 않았습니다. 저장된 템플릿은 그대로입니다(가져오기 전 6건, 후 6건).
  - (브라우저 원문: Unexpected token '이', "이 파일은 JSON이 아닙니다." is not valid JSON)
- 빈 파일
  - "empty.json": 빈 파일이라 가져오지 않았습니다. 저장된 템플릿은 그대로입니다(가져오기 전 6건, 후 6건).
- 필수 항목 누락 + 값 오류가 섞인 JSON(1번째만 정상)
  - "missing-required.json": 필수 항목이 빠졌거나 값이 잘못된 템플릿이 있어 아무것도 가져오지 않았습니다. 저장된 템플릿은 그대로입니다(가져오기 전 6건, 후 6건).
  - 2번째 항목("투명 PNG"): 필수 항목이 없습니다: color(문구 색)
  - 3번째 항목("세로 JPEG"): size(문구 크기) 값이 올바르지 않습니다. 24~240 사이의 숫자여야 합니다. (받은 값: "크게")
- templates 항목 자체가 없음
  - "no-templates.json": 템플릿 파일 구조가 올바르지 않아 가져오지 않았습니다. 저장된 템플릿은 그대로입니다(가져오기 전 6건, 후 6건).
  - 필수 항목이 없습니다: templates(템플릿 목록)
- format이 다른 파일
  - "wrong-format.json": 템플릿 파일 구조가 올바르지 않아 가져오지 않았습니다. 저장된 템플릿은 그대로입니다(가져오기 전 6건, 후 6건).
  - format 값이 올바르지 않습니다. "meme-card-studio-templates"이어야 합니다. (받은 값: "other-app")
- templates가 빈 목록
  - "empty-list.json": 템플릿 파일 구조가 올바르지 않아 가져오지 않았습니다. 저장된 템플릿은 그대로입니다(가져오기 전 6건, 후 6건).
  - templates가 비어 있어 가져올 템플릿이 없습니다.
- 이미지 본체가 PNG가 아님
  - "bad-image.json": 값이 잘못된 템플릿이 있어 아무것도 가져오지 않았습니다. 저장된 템플릿은 그대로입니다(가져오기 전 6건, 후 6건).
  - 2번째 항목("투명 PNG"): image.data가 PNG 이미지가 아닙니다.
- 이미지 크기가 적힌 값과 다름
  - "size-mismatch.json": 값이 잘못된 템플릿이 있어 아무것도 가져오지 않았습니다. 저장된 템플릿은 그대로입니다(가져오기 전 6건, 후 6건).
  - 2번째 항목("투명 PNG"): image의 width/height(999×600)가 실제 이미지 크기(600×600)와 다릅니다.
- id가 파일 안에서 중복
  - "dup-id.json": 값이 잘못된 템플릿이 있어 아무것도 가져오지 않았습니다. 저장된 템플릿은 그대로입니다(가져오기 전 6건, 후 6건).
  - 3번째 항목("세로 JPEG"): id가 2번째 항목과 같습니다. 파일 안에서 id는 겹치면 안 됩니다.
- 이름 비어 있음 + image 항목 없음(1번째)
  - "multi-problem.json": 필수 항목이 빠졌거나 값이 잘못된 템플릿이 있어 아무것도 가져오지 않았습니다. 저장된 템플릿은 그대로입니다(가져오기 전 6건, 후 6건).
  - 1번째 항목: name(이름) 값이 올바르지 않습니다. 공백을 뺀 1~40자여야 합니다. (받은 값: "")
  - 1번째 항목: 필수 항목이 없습니다: image(이미지)
