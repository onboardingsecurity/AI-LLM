## 4. 제출 화면의 규칙 (2026-11-05 사용자가 준 화면 이미지 기준)

| 항목 | 내용 |
|---|---|
| 결과물 URL | 선택. 제출하는 모든 URL은 계정 생성·로그인·인증·초대·비밀번호·OAuth·CAPTCHA 없이 새 시크릿 창에서 열려야 함(BRB-C15) |
| 파일 | 실행 묶음 ZIP 1~2개, 한 번에 10개·합계 8MB까지. 공개 결과물 URL만 내도 됨 |
| 제출 조건 | 결과 주소, 소스 주소 또는 제출 파일 중 하나는 있어야 제출됨. 화면에는 "소스 주소"도 보이나 입력 칸은 이미지에 없어 확인하지 못함 |
| 확인 방법·세 줄이 비었을 때 | 제출은 막히지 않지만 후행 채점에서 "기록 없음"으로 반영됨 |
| 업로드한 파일 | 비공개로 올라가고 학생 본인과 담당 강사·운영자만 볼 수 있음 |
