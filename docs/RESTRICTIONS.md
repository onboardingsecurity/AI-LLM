# 제한

기본은 금지이고, 필요한 것만 사용자 승인 후 허용한다.

## 키 값 금지

- API 키, 토큰, 비밀번호, 개인 키를 코드·문서·로그에 직접 적지 않는다.
- 키는 환경 변수로만 읽고, `.env` 같은 파일은 만들더라도 `.gitignore`에 포함한다.
- 보고할 때도 키 값은 앞 4글자만 보여주고 나머지는 가린다.

## 개인정보 금지

- 이메일, 전화번호, 주민등록번호, 카드번호, 실명 등 개인을 식별하는 값을 저장하지 않는다.
- 예시가 필요하면 `example.com` 도메인이나 명백한 가짜 값을 쓴다.

## 시스템 변경 금지

- 프로젝트 폴더 밖 파일 변경, 관리자 권한 실행, 스케줄러·시스템 설정 변경, 전역 패키지 설치를 하지 않는다.

## 외부 연결 금지 (승인한 것만 예외)

- 사용자가 승인하지 않은 외부 주소로 연결하지 않는다. 승인한 주소는 아래에 적는다.
- 승인한 외부 주소: github.com/onboardingsecurity/AI-LLM (과제 3·4 소스 위치)

## 작업 방식 제한

- AI는 허락 없이 파일을 만들거나 고치거나 지우지 않는다.
