# 5단계 점검 결과 (완성 이미지 3개)

완성 이미지는 앱 화면에서 실제로 문구와 화면비를 정해 PNG로 내려받은 파일이다. (이 결과는 자동 점검 스크립트로 만들었으나, 스크립트는 저장소에서 삭제했다. 앱을 고치면 결과가 어긋날 수 있다.)
C29(개인정보), C30(비밀값), C31(짧은 확인 방법), C32(제출문)는 사용자 담당이라 여기서 판정하지 않는다.

|---|---|---|---|---|---|---|---|

| [card-9x16.png](../samples/final/card-9x16.png) | 9:16 | 1080×1920 | 천천히 가도 괜찮아 / Keep going | bg-9x16.png | 열림 | 기록됨 | 0건 |
