# 2단계 대조 결과: 미리보기와 내려받은 파일

검사 방법: 브라우저(Chrome)에서 실제로 PNG를 내려받은 뒤, 화면의 미리보기 캔버스와 파일을 같은 좌표로 비교했다.
(이 결과는 자동 점검 스크립트로 만들었으나, 스크립트는 저장소에서 삭제했다. 앱을 고치면 결과가 어긋날 수 있다.)

검사 문구(3줄): `왼쪽끝 ← → 오른쪽끝 / 두 번째 줄 ABC 가나다 / 세 번째 줄` (색 #ff00ff, 크기 90)

판정 기준
- 이미지 잘림: 원본의 흰 테두리가 캔버스 네 가장자리 중 어디에 남아야 하는지 수식으로 예측하고, 미리보기와 파일이 모두 그와 같은지 확인한다.
- 문구 위치: 문구 색 픽셀의 경계 상자와 개수가 미리보기와 파일에서 같은지 확인한다.
- 줄바꿈: 문구가 3줄로 나뉘는지 미리보기와 파일에서 각각 센다.
- 참고: 미리보기와 파일의 모든 픽셀이 같은지도 함께 센다. 다른 픽셀 수가 0이어야 한다.
