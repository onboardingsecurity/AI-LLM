# 4단계 점검 결과: 템플릿 만들기, 불러오기, 수정, 삭제와 새로고침

검사 방법: Chrome에서 실제 화면을 조작하고, IndexedDB에 저장된 내용을 직접 읽어 대조했다. (이 결과는 자동 점검 스크립트로 만들었으나, 스크립트는 저장소에서 삭제했다. 앱을 고치면 결과가 어긋날 수 있다.)
데이터 항목 정의는 [template-schema.md](template-schema.md)에 있다.

## 시나리오

1. 템플릿 3개 생성: 이미지 없음(9:16, 이름을 비워 자동 이름), 가로 PNG(1:1), 세로 JPEG(4:5)
2. 편집 내용을 바꿔 둔 뒤 3개를 차례로 불러와 저장 당시와 대조(미리보기 픽셀 포함)
3. '셋째'만 수정(문구, 색, 크기, 이름, 메모)하고 저장소에서 나머지 두 개가 그대로인지 확인
4. 가운데 '둘째'를 삭제(먼저 취소, 다음 확인)하고 나머지가 그대로인지 확인
5. 새로고침 뒤 저장소와 목록이 그대로인지, 수정한 내용이 복원되는지 확인
