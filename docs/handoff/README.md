# 인수인계·비교 기록

작업 전에 값을 채우고, 작업 중에는 아래 순서대로 기록을 남긴다. 빈칸은 지어내지 않고 비워 둔다.

| 파일 | 용도 | 관련 조건 |
|---|---|---|
| `frozen-checks.md` | 고정 검사 10개와 공통 상한, 검사 정의 해시 | C01~C06, C18~C20 |
| `work-log.md` | A 시작 → A 종료·인수인계 → B 시작 → B 종료 기록, 사용량, 버전 ID | C07~C09, C26, C50~C53 |
| `HANDOFF.md` | 7항목 인수인계 문서 (AI A가 종료 때 작성) | C10~C15 |
| `comparison.md` | A/B로 가린 비교표 | C23~C28 |
| `name-mapping.md` | A/B의 실제 서비스·모델 이름 (판정 구간 뒤 공개) | C28, C39 |

각 파일의 템플릿은 첫 작업 시작 때 사용자 허락을 받아 만든다.
