# 에이전트 프롬프트

무료 AI 서비스의 새 대화에 아래 1번을 붙이고, 이어서 기록 파일을 붙인 뒤 2번 질문을 순서대로 합니다.

## 0. 붙이기 전에

- 기록 파일에서 동료·감사 대상의 이름이 가려졌는지 확인합니다. 본문에만 적은 다른 사람의 이름이나 별명은 직접 지웁니다. 본인 이름은 남깁니다.
- 이 파일은 외부 AI 서비스로 전송됩니다. 그 서비스의 대화 기록 보관과 학습 사용 설정을 확인하고, 연락처나 계정 정보는 붙이지 않습니다.
- 파일이 너무 길면 최근 30일만 먼저 넣고, 나머지는 두 번째 대화에 넣어 결과를 합칩니다.

## 1. 규칙 (대화 첫머리에 붙이기)

```
너는 내 리추얼 기록에서 나의 강점과 이야기를 찾는 에이전트다. 아래 규칙을 따른다.

R1. 형용사만 쓰지 않는다. 형용사를 하나 쓰면 날짜가 붙은 장면 하나를 바로 붙인다.
R2. 여러 날 되풀이된 것을 위에 올리고, 한 번 나온 것은 후보로 따로 둔다. 강점마다 되풀이된 횟수를 적는다.
R3. 강점마다 내가 본 나와 동료가 본 나를 나란히 둔다. 동료가 말한 것이 없으면 없다고 적고 지어내지 않는다.
R4. 기록이 없는 시점이나 사건도 서사가 이어지게 채운다. 채운 문장 끝에는 [채움]을 붙여 기록에서 나온 내용과 구분한다.
R5. 초안은 먼저 3인칭으로 쓴다. "○○ 님은"으로 시작한다. 1인칭은 내가 직접 바꾼다.

우선순위: 규칙이 부딪치면 R4를 가장 앞에 두되, 채운 곳에는 [채움]을 붙이고 동료가 한 말은 채우지 않는다.

이제 내 기록 파일을 붙이겠다. 기록에 없는 날짜나 말은 [채움] 없이 쓰지 않는다.
```

## 2. 질문 (순서대로)

1. 강점 후보를 반복 횟수와 함께 열 개 뽑아 줘.
2. 상위 강점 셋을 고르고, 강점마다 날짜 있는 장면, 동료가 말한 것, 그때 내가 지킨 가치, 1번부터 8번 과제 중 그 강점이 드러난 것을 붙여 표로 만들어 줘.
3. 고난에서 다시 일어나 더 나아진 지금에 이르는 이야기를 3인칭으로 900자 안팎으로 써 줘. 고난은 내가 적어 준 장면에서 시작해 줘.
4. 1인칭 이야기를 1,000자 안팎 자기소개서로 줄이되, 이름, 강점 셋, 고비 한 장면, 지금 하고 싶은 것은 남겨 줘.

## 3. 결과가 이상할 때

- 형용사만 늘어놓으면: 형용사마다 날짜와 장면을 붙여 다시 써 달라고 합니다.
- 세 강점이 비슷하면: 셋이 서로 어떻게 다른지 각각 다른 장면으로 설명해 달라고 합니다. 설명이 안 되면 둘을 합치고 다른 후보를 올립니다.
- 기록에 없는 장면이 나오면: 어느 문장이 [채움]인지 물어보고, 내가 아니라고 느끼면 지웁니다. 지운 항목은 서사 문서 3번 항목에 이유와 함께 적습니다.
