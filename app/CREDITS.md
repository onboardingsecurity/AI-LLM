# 출처와 사용 허가 근거

이 앱의 화면 스타일은 같은 저장소의 `ai-second-plan-do-see-diary` 브랜치(플랜두씨 다이어리), 12번 사이트(`ai-site-to-introduce-my-self-page`)와 같은 분위기입니다. 아래 앞의 네 파일은 그 브랜치의 파일을 그대로 복사했습니다(해시 동일).

| 파일 | 출처 | 사용 허가 근거 |
|---|---|---|
| fonts/jua-regular.ttf | Jua(배민 주아체) Regular, 제작 우아한형제들(The Jua Project Authors). Google Fonts의 공개 저장소(google/fonts, ofl/jua)에서 받은 파일을 그대로 사용. 화면에서 외부로 내려받지 않고 이 폴더의 파일을 씀 | SIL Open Font License 1.1(전문과 저작권 표기는 fonts/OFL-Jua.txt) |
| assets/background.png | 본인 제작(AI 생성). ChatGPT(gpt-image)로 직접 생성한 이미지 | OpenAI 이용약관 |
| assets/left.png | 본인 제작(AI 생성). ChatGPT로 직접 생성한 캐릭터 이미지 | OpenAI 이용약관 |
| assets/mouse-cursor.png | 본인 제작(AI 생성). ChatGPT로 직접 생성한 마우스 커서 이미지 | OpenAI 이용약관 |
| assets/small-space-640.png | 본인 제작(AI 생성). 본인이 ChatGPT 이미지 생성으로 직접 만든 배경 없는 이미지(누워 있는 공룡). `ai-second-plan-do-see-diary` 브랜치의 파일을 그대로 복사했다(해시 동일). 파일에 생성 도구 정보나 위치 정보 같은 메타데이터는 없음 | OpenAI 이용약관 |
