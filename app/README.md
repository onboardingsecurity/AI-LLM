# 대구 직업 호칭 가격 비교 (가제)

대구에서 네일샵을 고르는 손님이 두 가게의 호칭과 손 젤 원톤 가격을 넣으면, 그 가격 차이를 호칭 탓으로 볼 근거가 있는지 논문 결과로 알려 주는 앱입니다.

논문: 네일샵 시술자 호칭 유형과 손 젤 원톤 가격 수준의 관계: 대구 지역 탐색적 비교

## 실행 방법

설치할 것이 없습니다.

1. 압축을 풀고 `index.html`을 더블클릭해서 브라우저로 엽니다.
2. 직업 선택 화면에서 첫 번째 그림(손톱, 네일)을 누릅니다. 자물쇠가 붙은 나머지 직업(요리사 vs 쉐프, 개발자 vs 엔지니어)은 논문에서 아직 다루지 않아 누르면 안내만 뜹니다.
3. 가게 두 곳의 호칭을 누르고 가격을 넣은 뒤 "비교하기"를 누릅니다.

## 환경 변수

없습니다. AI 서비스를 부르지 않고 브라우저 안에서만 계산하므로 키가 필요 없습니다.

## 파일

| 파일 | 내용 |
|---|---|
| `index.html`, `style.css` | 화면과 스타일 |
| `script.js` | 화면 동작(알림 창, 클릭 효과, 호칭 고르기) |
| `logic.js` | 판단 규칙(가격 차이와 기준 금액 비교, 가격 범위 위치) |
| `data.js` | 논문 표 1의 호칭별 수치와 기준 금액 5,000원 |
| `messages.js` | 결과에 붙는 문장 |
| `fonts/` | 주아체 글꼴과 그 라이선스 |
| `assets/` | 배경, 캐릭터, 마우스 커서, 직업 선택 그림(`assets/icons/`) |
| `CREDITS.md` | 글꼴과 이미지의 출처와 사용 허가 근거 |
| `vercel.json` | 공개 URL로 올릴 때 쓰는 보안 헤더 설정 |

## 논문 결과를 쓰는 방법

- 두 가게의 가격 차이를 논문의 기준 금액 5,000원과 비교합니다. 5,000원은 설문 응답자 30명이 "확실히 다르다"고 느낀 가격 차이의 중앙값입니다.
- 각 가격이 논문의 같은 호칭 가게들의 가격 범위(중앙값, 가운데 절반, 최저, 최고) 어디에 있는지 보여 줍니다.
- 비교할 수 있는 호칭은 논문에서 5곳 이상이었던 원장, 디자이너, 아티스트, 네일리스트, 선생님입니다.
- 논문은 호칭 유형에 따라 가격이 다르다는 뚜렷한 증거는 확인되지 않았다고 정리했고, 인과는 말하지 않았습니다. 이 앱도 호칭이 가격을 정한다고 말하지 않습니다.

## 데이터

논문 표 1의 요약 수치만 들어 있습니다. 가게 이름, 시술자 이름 같은 개인정보나 가게 단위 원자료는 없습니다. 입력한 값은 브라우저 밖으로 나가지 않습니다.
